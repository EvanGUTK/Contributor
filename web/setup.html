Connect Contributor to your AI assistant.

The Contributor MCP server gives Claude, Codex, and Hermes direct access to GitHub opportunity discovery — no copy-paste needed.

These commands are setup starting points. Live handshakes with each client have not been verified yet — confirm tool discovery in a real session, and follow your client's own mcp add --help if the syntax differs.

01 / CLAUDE CODE

Claude Code

  1. Step 1 — Install dependencies (one-time)

    cd /path/to/contributor && npm install

  2. Step 2 — Add to Claude Code

    claude mcp add --transport stdio contributor -- node /absolute/path/to/contributor/apps/mcp/server.mjs

  3. Step 3 — Ask Claude

    Find me five Python open-source issues I could work on this weekend

02 / CODEX CLI

Codex CLI

  1. Step 1 — Install dependencies (one-time)

    cd /path/to/contributor && npm install

  2. Step 2 — Add to Codex via the CLI (use its built-in MCP management; don't overwrite an existing ~/.codex/config.toml)

    codex mcp add contributor -- node /absolute/path/to/contributor/apps/mcp/server.mjs

  3. Step 3 — Ask Codex

    Use Contributor to find JavaScript repos with beginner-friendly issues

03 / HERMES

Hermes

  1. Step 1 — Install dependencies (one-time)

    cd /path/to/contributor && npm install

  2. Step 2 — Add the MCP server in Hermes settings

    hermes mcp add contributor -- node /absolute/path/to/contributor/apps/mcp/server.mjs

  3. Step 3 — Ask Hermes

    Search Contributor for open-source AI projects I could contribute to

04 / AVAILABLE TOOLS

Available tools

ToolWhat it does
discover_opportunitiesPrimary entry point: find public repositories, issues and PRs for you.
find_review_requestsFind open public pull requests without submitted reviews.
inspect_repositoryRead public repository metadata: language, activity, issues and license.
get_repository_passportSummarize whether a repository looks ready for outside contributors.
analyze_issueFetch issue context and produce a safe starter plan prompt.
analyze_pull_requestFetch PR metadata and changed-file summaries for human-led review.
prepare_review_checklistGenerate a structured review checklist for a PR you selected; posts nothing.
prepare_contributionGenerate an approval-first handoff prompt for an opportunity you chose.
get_contribution_statusRead the current public state of an issue or pull request.
request_memory_handoffLet your assistant declare which preferences you approved sharing.

05 / OPTIONAL

GitHub token for higher rate limits

No token is needed for anonymous use. If you hit GitHub's public API rate limit, set CONTRIBUTOR_GITHUB_TOKEN in the environment of the MCP server process. Use a minimal, read-only token and never commit it to a config file.

export CONTRIBUTOR_GITHUB_TOKEN=<your-read-only-token>

Then start your assistant from that shell so the server inherits the variable.
