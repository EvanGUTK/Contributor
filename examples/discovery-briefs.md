# Example prompts for Contributor MCP

## First contribution

> Use Contributor to find five actively maintained Python repositories with beginner-friendly issues. I can spend three hours, and I enjoy computer vision. Explain what I should verify with maintainers before choosing.

## Technical review

> Use Contributor to find open PRs in Go developer tools where a thoughtful external review might help. Inspect the diff for one I select, explain its tests and possible edge cases, and draft a comment. Do not post anything.

## Hermes memory-aware matching

> Hermes, you already know my development interests. With my permission, extract only the topics/languages relevant to contribution discovery, then use Contributor MCP to find several open-source projects worth my time. Don't send raw memory notes, private data or my conversation history.

## Skills-building

> Use Contributor to find opportunities involving C++ and Linux, sorted toward beginner-friendly tasks appropriate for someone familiar with Python. Explain the learning objectives and likely prerequisites.

## Maintainer-first etiquette

> Before we work on a GitHub issue, verify it is current, check CONTRIBUTING.md and the AI-assisted contribution policy, determine whether there is a linked PR, and propose a respectful clarification question only if needed. No automated comments.
